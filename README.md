# Simple Interest Calculator

A Bash script that calculates simple interest given principal, annual rate of interest, and time period in years.

## Description
This script calculates simple interest based on user inputs: principal amount, annual interest rate, and time period in years.

## Input Parameters
* `p`: Principal amount
* `r`: Rate of interest per year
* `t`: Time period in years

## Formula
$$\text{Simple Interest} = \frac{p \times r \times t}{100}$$

## Output
* `Simple Interest` = (p * r * t) / 100

## Usage
```bash
chmod +x simple-interest.sh
./simple-interest.sh
